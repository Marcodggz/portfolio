## Highlights

- Responsive layout built for desktop, tablet, and mobile screens.
- Semantic HTML and keyboard-friendly navigation, including a skip-to-content link.
- English/Spanish language switcher with centralized, type-safe translation data.
- Component-based structure with page-level and shared UI components.
- Project content kept separate from presentation in typed data modules.
- Contact form with client-side validation and a configurable Formspree endpoint.
- SPA routing configured for Vercel deep links.
